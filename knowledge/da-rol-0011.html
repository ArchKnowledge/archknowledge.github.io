Role · Architecture

Solution Architect

Architect responsible for the design of a specific solution within enterprise and data architecture constraints.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Purpose

Deliver solution designs that honour higher-layer decisions.

Responsibilities

  • Design solution components and interfaces.
  • Select integration style per flow (Select Data Integration Style Professional).
  • Escalate when higher-layer decisions cannot be honoured.

Decision Rights

Technical level within standards; data architecture choices for the solution below threshold.

Inputs

Requirements; data architecture; platform standards.

Outputs

Solution designs; solution ADRs.

Required Competencies

Solution design; integration; delivery.

Escalation Paths

Conflicts with data architecture → Data Architect.
