Data Integration

The combination of data from different sources, and its movement between systems, so that it can be used consistently for a shared purpose.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Definition

Data Integration is the combination of data from different sources, and its movement between systems, so that it can be used consistently for a shared purpose.

Explanation

Integration styles differ in latency, coupling, and where transformation happens:

Style Latency Coupling Pattern
Batch hours–days low runtime coupling Batch Extract-Transform-Load
Change-based seconds–minutes medium Change Data Capture
Event-based seconds domain events as contract Event Sourcing / event streaming
Virtual query-time high runtime coupling Data Virtualization

The semantic side of integration (do these fields mean the same?) is often the harder part; see Meaning Before Representation. Interfaces should be governed by explicit data contracts. Anti-pattern: Point-to-Point Integration Sprawl.

Distinctions

  • Integration vs Data Migration: permanent vs transitional.

Examples

  • Replicating customer changes from CRM to the data warehouse via CDC every minute.
