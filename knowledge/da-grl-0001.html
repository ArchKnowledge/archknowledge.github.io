Governance rule · Architecture Governance

Status Change Requires Governance Record

An object may only be approved, published, implemented, deprecated or retired when an append-only governance record establishes that transition for its current version.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Rule

Changing status approves nothing. The validator (E092) rejects any object in an approved state without a governance record for its current version in 00-system/governance/records/; the governance-check workflow (G04) requires the record to be added in the same pull request.

Rationale

A contributor must not be able to make knowledge authoritative by editing one field. Approval is a recorded decision by people with decision rights.

Scope

All knowledge objects.

Enforcement

Automated: E092, E098 (records are append-only), G04. Machine definition: approval-rules.yaml AR-001.

Exceptions

None.
