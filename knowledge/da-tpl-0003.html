Template · Data Modeling

Data Model Review Checklist

Checklist for reviewing a data model at its layer, derived from the principles, patterns and anti-patterns in this knowledge base.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Purpose

Structured review of a Data Model submission.

Template

# Check Source knowledge Result (yes/no/n.a.) Note
1 The model states its layer (conceptual / information / logical / physical). Architecture Layer
2 Every entity/class links to a governed concept. Concept-to-Model Traceability
3 No attribute carries more than one meaning. Overloaded Attribute
4 History requirements are stated per entity and the mechanism is justified. Historical Requirements Are Explicit
5 Authoritative source is identified for shared entities. Each Data Element Has an Authoritative Source
6 Reference data uses governed code lists. Reference Data
7 Quality rules are specified for critical attributes. Data Quality Rule Specification Professional
8 Classification is set for sensitive data. Security Classification Control Professional
9 Decisions taken are recorded as ADRs. Architecture Decisions Are Traceable
10 No decisions belonging to another layer are made implicitly. Decisions Belong to Their Layer

Usage Guidance

Binary results are intentional: the checklist gates approval; maturity is assessed separately.
