Principle · Architecture

Each Data Element Has an Authoritative Source

For every shared data element, exactly one authoritative source is designated; other copies are derived and traceable to it.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Statement

For every shared data element, exactly one authoritative source shall be designated; other copies are derived and traceable to it.

Rationale

Multiple uncoordinated sources of the same fact produce contradictory answers and unresolvable reconciliation disputes.

Implications

  • Authoritative source is recorded as metadata per data element or data set.
  • Copies are read-only derivations with lineage.
  • Where several systems legitimately create the same entity, a Master Data Hub defines authority per attribute.

Consequences

  • Positive: defensible answers, simpler integration.
  • Negative: may require re-platforming data entry.

Applicability

Shared master, reference and key transactional data.

Exceptions

Transitional states during Data Migration, explicitly time-boxed.
