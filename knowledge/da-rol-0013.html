Role · Data Security & Privacy

Security Architect

Architect responsible for security architecture, classification schemes and security controls for data.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Purpose

Protect data according to its classification and risk.

Responsibilities

  • Define classification scheme and security controls.
  • Review designs for security.
  • Advise on access models.

Decision Rights

Security controls and classification rules; veto on security grounds via escalation.

Inputs

Risk assessments; regulations; designs.

Outputs

Security requirements; review outcomes.

Required Competencies

Security architecture; IAM; cryptography.

Escalation Paths

Risk acceptance → risk owner / Data Owner.
