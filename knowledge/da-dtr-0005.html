Semantic Modeling Approach Decision Tree

Guides the choice of semantic model formality — controlled vocabulary, SKOS taxonomy/thesaurus or OWL ontology.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Purpose

Select the formality of a Semantic Model; input to Select Semantic Modeling Formalism Professional.

Entry Question

Q1. Must machines infer new facts or check logical consistency from the model?

Decision Logic

Machine-readable in decision_logic (front matter); run it with python 00-system/validation/dakb.py decide "Semantic Modeling Approach Decision Tree". The rendering below is generated by dakb.py index.

  • q1. Must machines infer new facts or check logical consistency from the model? semantic.reasoning_required
    • YES → OWL ontology: Ontology, OWL 2
      • then:
        • q3. Will data models represent these concepts? semantic.represented_in_data_models
          • YES → Link model elements to concepts: Concept-to-Model Traceability
          • NO → Semantic model maintained on its own: —
    • NO →
      • q2. Are hierarchy, synonyms or mappings to external vocabularies needed? semantic.hierarchy_or_mappings
        • YES → SKOS taxonomy or thesaurus: Taxonomy, SKOS
          • then:
            • q3. Will data models represent these concepts? semantic.represented_in_data_models
              • YES → Link model elements to concepts: Concept-to-Model Traceability
              • NO → Semantic model maintained on its own: —
        • NO → Controlled vocabulary: Controlled Vocabulary
          • then:
            • q3. Will data models represent these concepts? semantic.represented_in_data_models
              • YES → Link model elements to concepts: Concept-to-Model Traceability
              • NO → Semantic model maintained on its own: —

Outcomes

Each leaf above names the knowledge objects to evaluate. The tree recommends options; the decision itself is recorded as an architecture decision.

Assumptions

  • SKOS and OWL can be combined; the tree picks the primary formalism.

Limitations

  • Does not cover property-graph or UML-only semantic approaches.
