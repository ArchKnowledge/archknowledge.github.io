Debezium

Open-source, log-based change data capture platform, commonly deployed on Kafka Connect, emitting row-level change events from databases.

Draft knowledge. Status proposed, quality draft. Not yet reviewed or approved by a human architect.

Purpose

Capture database changes from transaction logs and publish them as event streams.

Capabilities

  • Connectors for several relational and document databases.
  • Initial snapshots followed by streaming changes, including deletes.
  • Deployable as Kafka Connect connectors or as a standalone server for other sinks.

Limitations

  • Emits physical row changes; business meaning must be added downstream or via a Data Contract.
  • Dependent on source log configuration and retention.

Architecture Role

Technical implementation of Change Data Capture in Data Integration.

Applicable Patterns

Change Data Capture, synchronisation within Phased Data Migration.

Alternatives

Vendor CDC tools; database-native replication.

Integration

Typically: source DB → Debezium → Kafka topics → sink connectors / stream processing → platform.

Verification Notes

Supported connectors and deployment modes to be verified per version.
