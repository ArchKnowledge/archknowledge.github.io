Concept 1

  • Architecture LayerA level of abstraction in the architecture stack (business, conceptual, semantic, information, logical, physical, technical) with its own questions, artifacts and decision rights.

Decisions 4

  • Declare Epistemic Status on Every ObjectEvery knowledge object declares epistemic_status (verified fact, external standard, common practice, expert interpretation, recommendation, hypothesis, experimental) and confidence
  • Store Typed Relationships as Front-Matter KeysRepresent typed relationships as top-level front-matter keys named after controlled relationship types, each holding a list of wikilinks; store each edge once and derive inverses o
  • Use Markdown and Git as the Initial Knowledge StoreImplement the knowledge graph initially as Markdown files with YAML front matter in a Git repository, navigable in Obsidian, validated by a script.
  • Use Title-Based File Names for Knowledge ObjectsName each knowledge object file after its title (unique across the repository) and keep the immutable ID in front matter, so Obsidian wikilinks and graph labels are human-readable.
