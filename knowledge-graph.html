The model

Knowledge objects, connected by typed relationships

The graph has 155 objects and 388 relationships. Each relationship has a type from a controlled vocabulary, so it says how two pieces of knowledge relate, not just that they do.

Relationships are first-class knowledge

A statement like “a bitemporal data model realizes temporal data management” is itself knowledge. It can be validated (does the target exist?), queried (what realizes this concept?), governed (who approved it?) and reasoned over.

Generic related-to links are allowed only as a last resort; the validator warns when they dominate an object.

One source, many consumers

The knowledge lives as Markdown files with YAML metadata in Git. The same files are read by people in Obsidian and GitHub, by the validator, by this website, and by exporters that produce JSON, CSV and RDF (Turtle).

This website contains no copied knowledge: every page about an object is generated from its file at build time.
